## 完成内容与验收范围

- 原字典派生 27 个指标、38 个字段文档。统一 ID、类型、中文名、定义、来源、粒度、表、字段、稳定维度标识和限制，保留公式、默认时间、复合键、预聚合要求。
- 原关键词基线 v1 与可选依赖展开 v2 共用 Retriever 接口；业务输出函数不依赖具体实现。默认保持 v1。
- v2 仅从指标公式中的完整已有 metric_id 提取一层依赖，复制已有名称、定义、公式、限制及来源；对可识别的直接比值保存分子/分母角色。不是通用 SQL/公式解析器，不展开未知伪指标，不改写口径，也不改变允许维度。
- 15 题覆盖 9 道指标、4 道 Schema、2 道混合问题；保存逐题期望目标、实际文档、分数、排名、过滤条件及评分贡献；比较 k=1/3/5/10。
- 五题核心指标练习由用户查阅候选后回答；另有两题边界判断。新增八题按用户“你来审阅吧”的明确要求由助手按原字典和 DDL 审阅。正式集合区分 7 human_reviewed 和 8 assistant_reviewed，不宣称 15 题独立人工金标准。
- 五个短文本词频向量和 5×5 余弦矩阵实际计算；用户独立算对其中一组为 1/2。代码及其他矩阵结果由助手完成，不声称用户独立实现了余弦函数。
- 至少三个实际错误已有证据和分类，详见 DAY06_RETRIEVAL_ERRORS.md；进一步记录 v2 的退步。

## 复现命令

在项目根目录使用项目 .venv：

```powershell
# 全部测试
.\.venv\Scripts\python.exe -m pytest -q

# 15 题新旧基线比较，要求所有标签已经记录审阅来源
.\.venv\Scripts\python.exe -m src.ecommerce_agent.day06_benchmark --require-reviewed

# 单题，默认原基线；可选择 --retriever dependencies
.\.venv\Scripts\python.exe -m src.ecommerce_agent.day06_retrieval --question "商品价格在哪个字段" --type schema --top-k 3

# 五个短文本词频余弦实验
.\.venv\Scripts\python.exe -m src.ecommerce_agent.day06_cosine
```

命令会重建被 Git 忽略的 data/processed/retrieval/ 产物。单题命令覆盖 latest_result.json；比较命令输出完整 15 题结果。
