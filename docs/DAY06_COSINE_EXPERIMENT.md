# Day 6：五个短文本的词频余弦实验

本实验在关键词基线可测试后实施。文本、代码由助手准备，分数由本地 Python 实际计算；用户已独立回答 T1 与 T2 的余弦为 1/2。没有调用 Embedding 模型，没有测量模型 Token、费用或延迟，不代表真实语义检索的效果。

## 表示与计算

固定词表顺序为：商品、支付、金额、实付、钱款。文本以空格显式分词；每个坐标记录词出现次数，而非是否出现。

| 编号 | 文本 | 向量 |
|---|---|---|
| T1 | 商品 金额 | [1, 0, 1, 0, 0] |
| T2 | 支付 金额 | [0, 1, 1, 0, 0] |
| T3 | 支付 支付 金额 | [0, 2, 1, 0, 0] |
| T4 | 支付 金额 支付 金额 | [0, 2, 2, 0, 0] |
| T5 | 实付 钱款 | [0, 0, 0, 1, 1] |

cos(a,b) = sum(a_i × b_i) / (sqrt(sum(a_i²)) × sqrt(sum(b_i²)))。

示范 T2 与 T3：点积为 1×2 + 1×1 = 3，长度分别为 sqrt(2)、sqrt(5)，因此余弦为 3/sqrt(10)，实算约 0.948683。

所有坐标都翻倍的 T4 与 T2 同方向，实算余弦为 1。T5 与 T2 没有共享词项，实算为 0；这不能据此断言业务含义无关。词袋不含词序、同义关系、否定语义或时间间隔。使用余弦不等于使用学习得到的语义 Embedding。

余弦对零向量没有定义，代码明确抛出 ValueError；向量为空、维数不同、包含非有限值也拒绝计算。零分相似度与无法计算是两种不同情况。
