# 数据集说明：Olist Brazilian E-Commerce

## 选择结论

第一版使用 Olist 发布的 Brazilian E-Commerce Public Dataset。该数据集包含约
10 万笔 2016—2018 年的匿名订单，拆分为订单、订单明细、客户、商品、卖家、
支付、评价、地理位置和品类翻译 9 个 CSV 文件，适合练习多表 JOIN、指标口径、
Text-to-SQL 和结果校验。

## 来源与许可

- 发布者：Olist
- 数据页面：https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- 许可：CC BY-NC-SA 4.0
- 用途：仅用于非商业学习、作品集展示和研究；使用时保留署名，并遵守相同方式共享要求。
- 数据性质：真实商业数据的匿名化样本。

下载数据前，应在 Kaggle 登录并接受平台条款。原始 CSV 放入 `data/raw/`，不得
提交到 Git；下载方式和文件校验值将在实际下载后补充。

## 与项目需求的匹配

可以直接支持：

- GMV、订单量、客单价等基础经营指标；
- 时间趋势、地区、商品品类、卖家维度下钻；
- 订单、明细、支付等表之间的 JOIN；
- 取消、缺失时间、重复聚合和一对多关系等真实数据问题。

已知限制：

- 数据时间较旧，只用于技术验证，不用于描述当前市场；
- 原始数据没有可直接用于分析的明确“平台/渠道”字段；
- `seller_id` 表示卖家，不能冒充渠道；
- 后续若需要淘宝、京东、抖音等渠道维度，只能生成一个有清晰规则和随机种子的
  合成扩展表，并在 README、指标字典和演示中明确标为合成数据；
- 支付表和订单明细表都可能对一个订单产生多行，直接同时 JOIN 会造成指标膨胀。
