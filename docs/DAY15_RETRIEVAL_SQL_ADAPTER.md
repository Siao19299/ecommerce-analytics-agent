# Day 15 模块 4：检索 + SQL 版本适配器

## 1. 消融含义

本版本复用直接 SQL 的公开题面、静态六表 Schema、四动作输出合同、模型配置、单次
生成深度和错误处理，只增加现有 Day 6 `keyword-bigram-idf-v1` 检索结果。默认分别
取 metric top-5 与 schema top-8，与完整 Agent 的现有检索规模保持一致。

因此 V2−V1 是“加入当前词法检索包之后的配对差异”，其中同时包含检索内容、Prompt
长度和版式变化，不能外推为所有 RAG 方法的因果效果。

## 2. 检索证据

每题保存 retriever 版本、metric/schema top-k、文档 ID、类型、类型内排名和原始分数。
Prompt 中包含命中文档的名称、定义、公式、粒度、来源表、字段上下文、默认时间字段、
允许维度和限制。命中分数仅表示词法相关性，不是业务授权；字段上下文也不是任意 JOIN
许可。

指标字典仍是业务口径的规范来源，检索文档只是它的派生视图。本模块没有新增向量库、
Embedding、RAG 框架或在线服务。

## 3. 保持不变的边界

适配器没有 AnalysisPlan、状态机、候选系统内安全门、SQL 执行、修复或确定性计算。
它可输出 SQL、澄清、拒绝或无法回答；非 JSON 和结构错误原样保存且不发送纠错调用。
安全执行和私有评分仍由后续统一运行器完成。

## 4. 当前证据

当前测试使用真实本地词法检索器和 `FakeModelClient`，验证检索确定性、证据记录、共享
输出合同、无私有金标准内容、单次生成及未知用量不猜测。外部 API 调用和真实模型运行
均为 0，不产生候选准确率结论。
